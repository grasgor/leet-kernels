## Puzzles
This dir consists of kernels that solve questions on [LeetGPU](https://leetgpu.com/challenges) or [Tensara](https://tensara.org/problems/).

Not the most efficient, mostly done for playing around. Skips the usual gemm, gemv kernels and variants, find that in [arithmetic](../arithmetic)

- Restructure dir, leetgpu does not offer benchmarking in the free tier, while tensara provides access to all gpus with benchmarking
